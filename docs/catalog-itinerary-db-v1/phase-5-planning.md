# Phase 5 Planning — 공통축 T05~T08

**목표:** 코어 CRUD 안정 후 대량·반영·승인·이력의 **골격**. 운영 한도(D05~D08)는 자리만 둔다.

## 1. 목표·범위·비범위

- In: 선택 유지(A01 보강), 일괄 필드 수정 미리보기, 사용처 조회 자리, 임시 요소 상태, 변경 이력 목록
- Out: 엑셀 다중 시트 확정(D05), 전체 트랜잭션 약속(D08), 영구삭제·휴지통 정책(D06), 역할별 승인(D07)

## 2. 화면/스토리

| 코드 | 내용 | 1차 골격 |
|------|------|----------|
| T05-01 | 선택 항목 일괄 수정 | 상태/권역 등 단순 필드. 전후 미리보기 후 실행 |
| T05-02 | 엑셀 일괄 | UI만. 파일 파싱 없음 |
| T06-01 | 사용처·변경 영향 | 요소→세트/블록/여정 참조 목록 |
| T06-02 | 반영안 검토 | 선택 반영 체크 UI. 실제 버전 전파는 최소 |
| T07-01 | 임시 요소 승인 | `DRAFT`/`PENDING`/`ACTIVE` 상태 전환 |
| T08-01 | 이력 | 최근 변경 시각·작업자 자리. 시스템 로그 테이블 최소 |
| T08-02 | 공통 적용표 | 문서 링크. 화면 아님 |

T09는 메뉴가 아니라 통합 검수 시나리오 → 각 Phase DoD에 사례 ID로 연결.

## 3. 데이터·API 변경

- `CatalogUsageStatus`에 `DRAFT`를 넣지 않고, Element에 `lifecycleStatus` optional (`ACTIVE` 기본, `PENDING_REVIEW`)
- `CatalogChangeLog`: actorLabel, targetType, targetId, action, summary
- 일괄 update는 기존 update mutation 반복 + 행별 결과 배열
- 사용처: Element를 가리키는 setItems / block placements / journey는 간접(block←element)

## 4. UI 구조

- 각 목록의 기존 “대량 관리” stub을 선택 바 동작으로 연결
- 공통 모달: 필드 선택 → 미리보기 → 결과(성공/실패/미처리)
- 사용처 패널: 참조 건수 + 목록
- 이력 패널: 최근 N건

## 5. 검수표 매핑

- A01 선택 유지 재확인
- T05~T08는 골격 검수. 파일 한도·일괄 취소는 D05/D08 이후
