# deferred — 후순위

1차에 자리를 만들되 본구현하지 않는 항목. “개발 중 협의”라는 이유로 숫자를 코드에 고정하지 않는다.

## 화면

- T01-05 실측 통계 ~ T01-08 장소 판정·재분석 (D03, D04)
- T02-05/08 수식·문구 엔진 본구현 (D01, D02)
- T02-07 실측·성과 지표 고도화 (D09)
- T03-02 드래그 맞춤·자동이동·조 분리 (C03, C05~C08)
- 견적/확정 빌더 전면 연동 (D10)

## 협의 항목 (D01~D10)

| 번호 | 나중에 정할 것 | 지금 지키는 원칙 |
|------|----------------|------------------|
| D01 | 문구 생성 기술·연산자 | 조건 공간, 선택 적용. 저장 문구 자동 교체 금지 |
| D02 | 비용·피로도·포화도 공식 | 근거 표시, 중복 집계 방지, 예시식 고정 금지 |
| D03 | GPS 반경·체류 임계값 | 품질·표본·실측/추정 구분 자리 |
| D04 | API 키·필드·시간대 | 확인 전 연동 완료 표시 금지 |
| D05 | 파일 양식·건수 한도 | ID·임시키·미리보기 자리 |
| D06 | 휴지통·영구삭제 | 참조 보호, 복원은 새 버전 |
| D07 | 역할별 승인 세부 | 기존 직원 계정. 임시→정규 전환 자리 |
| D08 | 대량 작업 트랜잭션 | 행별 결과. 전체 성공 약속 없음 |
| D09 | 성과 분모·연동 시점 | `미연동` 표시 |
| D10 | 재발행·계약 개정 | 기존 스냅샷 보존. 빌더 미교체 |

## 표시 규칙

연결 전에는 `미연동`, 기록이 없으면 `자료 없음`, 값이 결정되지 않았으면 `미정`, 진짜 0이면 `실제 0`.
